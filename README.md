# আমার কাজ — বাংলা টু-ডু অ্যাপ

Flutter দিয়ে বানানো একটি সহজ টু-ডু অ্যাপ। সম্পূর্ণ বাংলা ইন্টারফেস।

## যা যা আছে

- কাজ যোগ করা (নাম, নোট, গুরুত্ব: জরুরি / সাধারণ / পরে হলেও চলবে, শেষ তারিখ)
- কাজের তালিকা: আজকের কাজ / অন্যান্য কাজ / হয়ে গেছে
- মেয়াদ পার হওয়া কাজ লাল চিহ্ন দিয়ে দেখায়
- টিক দিয়ে কাজ শেষ করা, এডিট করা, নিশ্চিত হয়ে মুছে ফেলা
- ফিল্টার: সব / বাকি / হয়ে গেছে; শেষ হওয়া সব কাজ একসাথে মোছা
- আজকের অগ্রগতি: "আজ Xটির মধ্যে Yটি কাজ শেষ"
- কাজগুলো ফোনেই সেভ থাকে (shared_preferences)

## APK বানানো

`main` ব্রাঞ্চে পুশ করলেই GitHub Actions নিজে থেকে release APK বানিয়ে
Actions run-এর Artifacts-এ `amar-kaj-apk` নামে আপলোড করে দেবে।
